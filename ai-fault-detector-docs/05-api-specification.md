# API Specification — VisionGuard AI

Base URL: `https://<host>/api/v1` (local dev: `http://localhost:8100/api/v1`).
Interactive docs: `/docs` (OpenAPI generated by FastAPI; this document is the contract it must match).

## 0. Conventions

**Authentication**
- Users: `Authorization: Bearer <access_token>` (JWT, 15 min) + refresh token (7 days, rotated on use, stored hashed).
- Integrations: `X-API-Key: <key>` with scopes, e.g. `events:read` or `actions:request`.

**Roles** (same names as the database)

| Role | Can |
|---|---|
| `super_admin` | Everything, across all customers |
| `customer_admin` | Manage own customer's sites, cameras, zones, rules, users, models, channels |
| `operator` | Live view, review events, trigger manual actions that need no approval |
| `viewer` | Read dashboards, events and reports |

**Tenancy:** every request is scoped to the caller's `customer_id`. Requests for another customer's resources return `404`, never `403`, so IDs don't leak.

**Pagination:** `?limit=50&cursor=<opaque>`, with `limit` capped at 200. Responses look like:
```json
{ "items": [...], "next_cursor": "eyJ0IjoiMjAyNi0xMS0wN1QxMDowMDowMFoifQ" }
```

**Errors:** RFC 9457 problem details:
```json
{ "type": "https://visionguard.ai/errors/validation", "title": "Validation failed",
  "status": 422, "detail": "min_confidence must be between 0 and 1", "errors": [{"field":"min_confidence"}] }
```

**Idempotency:** `POST` endpoints that cause side effects (`/actions`, `/alerts/test`, `/training/jobs`) accept an `Idempotency-Key` header.

**Coordinates:** relative, 0–1, origin top-left.

**Times:** ISO-8601 with offset. Reports group by the site's timezone.

## 1. Health
| Method | Path | Notes |
|---|---|---|
| GET | `/health` | Liveness. No auth |
| GET | `/health/ready` | DB, Valkey, MQTT and Frigate reachability. `super_admin` only |

## 2. Auth
| Method | Path | Notes |
|---|---|---|
| POST | `/auth/login` | `{email, password}` → `{access_token, refresh_token, user}`. Rate-limited: 5 attempts/min per IP+email |
| POST | `/auth/refresh` | `{refresh_token}` → new pair; the old refresh token is revoked |
| POST | `/auth/logout` | Revokes the refresh token |
| GET | `/auth/me` | Current user and permissions |

There is no public self-registration. Users are created by an admin (see §3).

## 3. Customers, users, sites
| Method | Path | Role |
|---|---|---|
| GET/POST | `/customers` | super_admin |
| GET/PATCH | `/customers/{id}` | super_admin; customer_admin (own, limited fields) |
| GET/POST | `/users` | customer_admin |
| PATCH/DELETE | `/users/{id}` | customer_admin |
| GET/POST | `/sites` | customer_admin (POST); all (GET) |
| GET/PATCH/DELETE | `/sites/{id}` | customer_admin |

`POST /sites`
```json
{ "name": "Kigali Restaurant", "location": "Kigali, Rwanda", "timezone": "Africa/Kigali",
  "business_hours": { "mon": [["08:00","22:00"]], "sun": [] } }
```

## 4. Cameras & screens
| Method | Path | Role |
|---|---|---|
| GET | `/cameras?site_id=` | all |
| POST | `/cameras` | customer_admin |
| GET/PATCH/DELETE | `/cameras/{id}` | customer_admin (write) |
| GET | `/cameras/{id}/status` | all. `{status, fps, last_seen_at, last_event_at, active_model}` |
| GET | `/cameras/{id}/snapshot` | all. Latest frame (proxied from Frigate) |
| GET | `/cameras/{id}/stream` | all. Short-lived signed go2rtc WebRTC/MSE URL |

`POST /cameras`
```json
{ "site_id": "uuid", "name": "Entrance Camera", "source_type": "rtsp",
  "source_url": "rtsp://user:pass@192.168.1.10:554/Streaming/Channels/102",
  "frigate_name": "entrance", "resolution": "1280x720", "fps": 5 }
```
`source_url` is **write-only**. It is encrypted at rest, and responses return `"source_url_set": true` instead.

## 5. Zones
| Method | Path | Role |
|---|---|---|
| GET | `/zones?camera_id=` | all |
| POST | `/zones` | customer_admin |
| PATCH/DELETE | `/zones/{id}` | customer_admin |

```json
{ "camera_id": "uuid", "name": "Restricted Area", "zone_type": "restricted",
  "frigate_zone": "restricted_area",
  "polygon": [[0.60,0.20],[0.95,0.20],[0.95,0.90],[0.60,0.90]] }
```
Polygons need at least 3 points (a `line` zone has exactly 2), and every value must be in [0, 1].

## 6. Rules
| Method | Path | Role |
|---|---|---|
| GET | `/rules?site_id=&camera_id=` | all |
| POST | `/rules` | customer_admin |
| GET/PATCH/DELETE | `/rules/{id}` | customer_admin |
| POST | `/rules/{id}/mode` | customer_admin. `{"mode":"live"}` or `{"mode":"shadow"}` |
| POST | `/rules/{id}/test` | customer_admin. Replays the last N hours of stored observations and returns the events that would have fired (no alerts are sent) |
| GET | `/rule-templates?industry=` | all. Built-in templates from `08-rules-and-actions.md` |

`POST /rules` — "more than 5 people in the queue for 2 minutes":
```json
{ "site_id": "uuid", "camera_id": "uuid", "zone_id": "uuid", "fault_type_id": "uuid",
  "name": "Long queue", "condition_type": "count", "object_class": "person",
  "params": { "operator": ">", "threshold": 5 },
  "min_confidence": 0.6, "duration_seconds": 120, "cooldown_seconds": 600,
  "schedule": { "mode": "business_hours" }, "severity": "medium", "mode": "shadow",
  "action_config": {
    "notify": [ { "channel": "telegram", "recipients": ["role:customer_admin"] } ],
    "save_clip": true, "clip_seconds": { "pre": 5, "post": 10 },
    "webhook": { "url": "https://example.com/hook", "secret_ref": "webhook_main" }
  } }
```
Webhook payloads are signed with HMAC-SHA256 in `X-VisionGuard-Signature`.

## 7. Events
| Method | Path | Role |
|---|---|---|
| GET | `/events` | all. Filters: `site_id, camera_id, rule_id, status, severity, fault_type_id, rule_mode, start, end`, plus cursor pagination |
| GET | `/events/{id}` | all. Includes signed `snapshot_url` and `clip_url` (5 min), deliveries, actions, feedback |
| PATCH | `/events/{id}/review` | operator+ |
| POST | `/events/{id}/feedback` | operator+ |
| POST | `/events/{id}/export` | customer_admin. Exports the clip (optionally face-blurred). Audited |
| WS | `/ws/events?token=` | all. Pushes `event.created`, `event.updated` and `camera.status` messages |

`PATCH /events/{id}/review`
```json
{ "status": "false_positive", "review_note": "Staff member cleaning" }
```
Allowed transitions: `open → acknowledged → resolved`, and `open|acknowledged → false_positive`. Each transition sets `*_by`/`*_at` and writes an audit log entry.

`POST /events/{id}/feedback`
```json
{ "label": "wrong_class", "corrected_class": "staff", "note": "Uniformed waiter" }
```

## 8. Models
| Method | Path | Role |
|---|---|---|
| GET | `/models` | all |
| POST | `/models/upload` | customer_admin. Multipart: file (`.onnx` preferred, `.pt` accepted), `name, version, architecture, license, classes` |
| GET | `/models/{id}` · `/models/{id}/metrics` | all. mAP@0.5, precision, recall, F1, latency, per-class metrics |
| POST | `/models/{id}/approve` | customer_admin |
| POST | `/models/{id}/activate` | customer_admin. `{"camera_ids":["uuid",...]}`. Fails with 409 if the model isn't approved or its licence isn't cleared for commercial use |
| POST | `/cameras/{id}/model/rollback` | customer_admin |
| GET | `/models/{id}/feedback-stats` | all. Precision estimated from operator feedback |
